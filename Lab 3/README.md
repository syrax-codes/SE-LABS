# Lab 3 – Architecture Design

## Remote Patient Vitals Alert & Monitoring App

This lab focuses on selecting a suitable architectural style and designing the system using a UML component diagram.

For our scenario, we selected **Microservices Architecture** because the system can be divided into independent services for telemetry ingestion, anomaly detection, emergency alert management, caregiver notification, patient monitoring, authentication and security, and telemetry storage.

The component diagram shows the main system components, their interfaces, and the interactions between them.
